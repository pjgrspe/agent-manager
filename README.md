# Claude Manager — Multi-Project Command Center

A lightweight Windows desktop & local web dashboard for managing multiple repositories with **Claude Code** and `pjgrspe/anti-slop-kit`.

## Run Modes

- **Local Web Dashboard:**
  ```powershell
  npm run dev
  ```
  Opens API on `http://127.0.0.1:4311` and UI on `http://localhost:5173`.

- **Windows Desktop App (Electron):**
  ```powershell
  npm run desktop
  ```

- **Verify Gate (Typecheck + Tests + Build):**
  ```powershell
  npm run verify
  ```
